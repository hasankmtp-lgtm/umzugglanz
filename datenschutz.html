2. Welche Daten wir bearbeiten

Offertanfrage (Formular, Telefon, WhatsApp, E-Mail)

Wenn Sie eine Offerte anfragen, bearbeiten wir die Angaben, die Sie uns machen: Name, Telefonnummer, E-Mail-Adresse, Auszugs- und Einzugsadresse, Wunschtermin und Angaben zum Objekt. Das Kontaktformular wird über den Dienst FormSubmit (formsubmit.co) übermittelt; die Angaben werden als E-Mail an info@umzugglanz.ch weitergeleitet und nicht dauerhaft beim Dienstleister gespeichert.

WhatsApp

Wenn Sie uns über WhatsApp kontaktieren, gelten zusätzlich die Datenschutzbestimmungen von WhatsApp (Meta Platforms Ireland Ltd.). Nutzen Sie bei Bedarf stattdessen Telefon oder E-Mail.

Zugriffsdaten (Hosting)

Diese Website wird über GitHub Pages (GitHub Inc., USA) ausgeliefert. Beim Aufruf werden technisch notwendige Daten wie IP-Adresse, Datum und Uhrzeit, aufgerufene Seite und Browsertyp in Server-Logs verarbeitet, um die Website sicher bereitzustellen. Schriftarten werden von Google Fonts (Google Ireland Ltd.) geladen; dabei wird Ihre IP-Adresse an Google übermittelt.

Diese Website setzt keine Tracking-Cookies und verwendet keine Analyse- oder Werbedienste.
